### 手动测试清单

#### 基础功能测试

- [ ] 在 Firefox 中打开网站，验证看板娘是否显示

- [ ] 在移动设备上打开网站，验证看板娘是否显示

#### 交互功能测试
- [ ] 鼠标移动时视线是否跟随
- [ ] 点击模型是否触发动画
- [ ] 点击"休息"按钮是否隐藏模型

#### 性能测试
- [ ] 页面加载速度是否受影响（应 < 500ms）
- [ ] 动画是否流畅（应 > 30fps）
- [ ] 长时间运行是否有内存泄漏
