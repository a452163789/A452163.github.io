## 技术栈

- **核心库**: oh-my-live2d (latest)
- **模型资源**: oh-my-live2d/live2d-models（官方高质量模型库）
- **CDN**: unpkg (库) + model.oml2d.com (模型)
- **加载方式**: 异步 CDN 引入
- **配置方式**: JavaScript 对象配置
- **API**: OML2D.loadOml2d()

## 配置调整指南

### 如果需要调整模型大小
编辑 `JS/live2d-config.js`:
```javascript
scale: 0.08,  // 调整这个值（0.05-0.15）
stageStyle: {
  width: 200,   // 调整宽度
  height: 280   // 调整高度
}
```

### 如果需要调整位置
```javascript
position: [0, 50],  // [x, y] 调整位置
```

### 如果需要更改提示语
```javascript
idleTips: {
  message: [
    '你的自定义消息 1',
    '你的自定义消息 2',
    // 添加更多...
  ]
}
```

### 如果需要添加更多模型
```javascript
models: [
  // 现有模型...
  {
    path: 'https://cdn.jsdelivr.net/gh/zenghongtu/live2d-model-assets@master/assets/模型名/模型名.model.json',
    scale: 0.1,
    position: [0, 50],
    stageStyle: {
      width: 250,
      height: 350
    }
  }
]
```

## 故障排除

### 如果看板娘没有显示
1. 检查浏览器控制台是否有错误
2. 确认网络连接正常
3. 检查 CDN 是否可访问
4. 验证配置文件路径正确

### 如果加载很慢
1. 检查网络速度
2. 考虑增加延迟时间
3. 考虑减少模型数量
4. 考虑使用更轻量的模型

### 如果性能不佳
1. 减小模型尺寸
2. 增加初始化延迟
3. 在低性能设备上禁用
4. 禁用某些功能（状态栏、菜单）
