## 调优建议

### 根据测试结果可能需要调整的参数

#### 如果模型太大
```javascript
// 减小 scale 值
scale: 0.08  // 从 0.1 改为 0.08
```

#### 如果模型位置不合适
```javascript
// 调整 position 值
position: [0, 80]  // 从 [0, 50] 改为 [0, 80]，向下移动
```

#### 如果提示语显示时间不合适
```javascript
// 调整 duration 和 interval
duration: 3000,   // 显示时长改为 3 秒
interval: 10000   // 间隔改为 10 秒
```

#### 如果初始化太快或太慢
```javascript
// 调整延迟时间
setTimeout(() => {
  // ...
}, 500);  // 从 1000ms 改为 500ms
```

#### 如果移动端模型太大
```javascript
// 调整移动端配置
stageStyle: {
  width: isMobile ? 150 : 250,   // 从 200 改为 150
  height: isMobile ? 210 : 350   // 从 280 改为 210
}
```
