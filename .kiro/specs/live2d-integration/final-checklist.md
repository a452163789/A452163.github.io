### 3. 查看页面右下角

应该看到 Live2D 看板娘（hijiki 模型）

## ❌ 如果看到错误日志

### 错误 1: "oh-my-live2d 脚本加载失败"

**原因**: CDN 无法访问

**解决方案**:
1. 检查网络连接
2. 尝试直接访问: https://cdn.jsdelivr.net/npm/oh-my-live2d@0.19.3/dist/index.min.js
3. 如果无法访问，使用备用 CDN（参考 `cdn-alternatives.md`）

### 错误 2: "OhMyLive2D 未加载"

**原因**: 脚本加载了但对象未定义

**解决方案**:
1. 清除浏览器缓存（Ctrl+Shift+Delete）
2. 强制刷新页面（Ctrl+F5）
3. 检查是否使用 HTTP 服务器（不是直接打开 HTML）
4. 尝试使用固定版本号（已经使用了 0.19.3）

### 错误 3: "已达到最大重试次数"

**原因**: 多次尝试后仍无法加载

**解决方案**:
1. 检查网络面板（F12 -> Network）
2. 查看 `index.min.js` 的加载状态
3. 如果状态码不是 200，说明 CDN 有问题
4. 尝试备用 CDN 或本地托管

## 🚀 启动服务器命令

确保使用以下命令之一启动服务器：

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js
npx serve

# PHP
php -S localhost:8000
```

然后访问: `http://localhost:8000/index.html`

## 📊 性能检查

### 使用 Chrome DevTools

1. 打开 Performance 面板
2. 刷新页面并录制
3. 检查以下指标：
   - FCP < 1.5s
   - LCP < 2.5s
   - TTI < 3.5s

### 使用 Network 面板

1. 查看 `index.min.js` 的大小和加载时间
2. 查看模型文件的大小和加载时间
3. 总加载时间应 < 3s（首次）
